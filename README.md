# Primeiro Emprego

Plataforma em desenvolvimento para conectar jovens em busca da primeira experiência profissional a empresas com oportunidades que não exigem experiência anterior.

## Status
**Protótipo / em desenvolvimento.**

## Objetivo
Facilitar o acesso de jovens a oportunidades de entrada no mercado de trabalho e oferecer às empresas um espaço para divulgação dessas vagas.

## Funcionalidades planejadas
- Cadastro e autenticação
- Perfil do jovem
- Perfil da empresa
- Publicação e consulta de vagas
- Candidaturas
- Painel de gerenciamento
- Filtros de oportunidades

## Princípios
- Interface simples e acessível
- Privacidade dos dados dos usuários
- Separação entre frontend, backend e dados
- Evolução incremental do protótipo
